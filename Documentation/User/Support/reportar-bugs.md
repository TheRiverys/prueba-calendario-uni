# 🐛 Cómo Reportar Problemas

## Antes de Reportar

### 🔍 Consulta la Ayuda Integrada
- Revisa la **guía de usuario** haciendo clic en ❓
- Consulta la **sección de solución de problemas**
- Busca en los **consejos prácticos** disponibles

### 📋 Información esencial para incluir
- **Descripción clara** del problema
- **Pasos para reproducirlo** (número por número)
- **Resultado esperado** vs **resultado obtenido**
- **Versión de la aplicación** y **sistema operativo**

## 📝 Información Necesaria

### Información Básica
- **Versión de la aplicación** (visible en Configuración → Información)
- **Sistema operativo** (Windows, macOS, Linux)
- **Navegador** (si usas la versión web)

### Descripción del Problema
- **¿Qué estabas haciendo cuando ocurrió?**
- **¿Qué resultado esperabas?**
- **¿Qué ocurrió realmente?**
- **¿Puedes reproducir el problema?**

### Recursos de Ayuda Disponibles
- **Guía integrada**: Usa el botón ❓ para acceder a la documentación completa
- **Sección de solución de problemas**: Disponible en la ayuda integrada
- **Consejos prácticos**: Incluidos en la guía de usuario

## 🚨 Problemas Comunes ya Documentados

### Consulta Primero la Ayuda Integrada
1. Haz clic en el botón ❓ en la aplicación
2. Revisa la sección **"Solución de Problemas"**
3. Consulta los **"Consejos Prácticos"** disponibles

### Problemas Comunes
- **No veo mis entregas**: Verifica filtros y configuración del semestre
- **Fechas de estudio no aparecen**: Revisa configuración de algoritmo
- **Problemas de rendimiento**: Cierra pestañas del navegador

## 📍 Dónde Reportar

### Correo Electrónico
- **Dirección**: info@corebsm.es
- **Asunto**: [Problema] Descripción breve del problema
- **Incluye**: Información detallada del problema

## 🎯 Mejores Prácticas

### Para reportar efectivamente:
1. **Sé específico** - detalles concretos ayudan más que "no funciona"
2. **Consulta primero la ayuda** - muchas soluciones ya están documentadas
3. **Sé paciente** - el soporte responde según disponibilidad
4. **Sé respetuoso** - el equipo trabaja para ayudarte

### Lo que NO hacer:
- ❌ No reportes el mismo problema múltiples veces
- ❌ No incluyas información personal sensible
- ❌ No uses lenguaje ofensivo o demandante

## 🔒 Privacidad y Seguridad

### Protección de Datos
- Cumplimos estrictamente con **RGPD**
- No compartimos información personal sin consentimiento

### Información Sensible
- No envíes información personal innecesaria
- Usa la aplicación para cualquier consulta sobre datos
